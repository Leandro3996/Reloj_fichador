El contexto de este proyecto es el siguiente: 

He creado un sistema de "Fichadas" para una empresa que sirve para controlar los horarios de entrada, salida, descansos (movimientos transitorios).
El sistema funciona correctamente en producción, está corriendo en un servidor con la dirección "192.168.10.39:5080 (Frontend)".

Actualmente estamos trabajando en el proyecto de pruebas, ya que estamos trabajando para mejorarlo y añadir funciones que el proyecto del servidor producción actualmente no tiene.

El proyecto comenzó siendo solo un software que registraba cada movimiento de entradas y salidas, y que sirve para controlar las asistencias, las faltas, la cantidad de horas trabajadas, el tiempo de descanso, etc.

Y luego hemos ido añadiendo algunas funciones que aún requieren ser terminadas, como por ejemplo todo el tema general de reportería y funciones como las licencias médicas, quizás en el futuro añadir funciones para vacaciones y luego quien sabe, el proyecto podría ser una herramienta super completa para el área "RRHH".
